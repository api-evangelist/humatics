# Humatics

> Humatics Corporation is a Waltham, Massachusetts microlocation company founded in 2015 by MIT
> professor David Mindell. It builds radio-frequency positioning systems — ultra-wideband beacons,
> RF-pulse ranging, radar and inertial sensors fused in software — that locate people, vehicles and
> robots at centimeter- to millimeter-scale precision, for industrial automation (MILO) and for rail
> and transit (FOCUS track monitoring, Humatics Rail Navigation System).

## API surface

Humatics publishes **no public product API**. As of 2026-08-04 there is no developer portal, no API
reference, no OpenAPI/Swagger/AsyncAPI/GraphQL description, no MCP server and no A2A agent card on
any humatics.com host. Every /.well-known/ path returns 404. `*.humatics.com` is a DNS wildcard onto
a single retired address, so api., docs., developer., portal. and status. all resolve but time out
on connect — none of them is a real host. Older marketing for the KinetIQ OS / Spatial Intelligence
Platform referred to an "extensible API", but no public interface for it was ever documented and the
host that carried those announcements (now.humatics.com) no longer answers. Product integration runs
through direct commercial engagement, not self-service onboarding.

The one machine-readable HTTP interface Humatics operates is the WordPress REST API of the marketing
site itself, at [https://humatics.com/wp-json/](https://humatics.com/wp-json/) — 375 routes across 19
namespaces, all of it stock WordPress core plus commercial plugins (Elementor, FluentForm, HubSpot,
Google Site Kit). It exposes pages and posts, not positioning, ranging, MILO, FOCUS or HRNS. It is
recorded in this profile as evidence, and deliberately not catalogued as a Humatics API.

## Products

- [MILO](https://humatics.com/milo/): Sub-millimeter real-time positioning for industrial automation
  and in-motion robotics. Advertised compatibility with Yaskawa, Mitsubishi Electric, FANUC,
  Universal Robots and KUKA. Applications: in-motion fastening in automotive assembly, semiconductor
  material handling, aerospace tool tracking, robotic alignment.
- [Mobility](https://humatics.com/mobility/): Rail and transit positioning and predictive
  maintenance. Includes the FOCUS track-geometry monitoring kit (cab computer plus roof-mounted
  IMU/GNSS enclosure) and the Humatics Rail Navigation System (HRNS), a UWB + IMU + GNSS sensor
  fusion navigation system feeding train control. Deployed on New York City MTA subway signalling
  projects.

## Code

- [github.com/Humatics](https://github.com/Humatics): Real, public GitHub organization with 33
  repositories. Note that these are almost entirely **forks** of third-party embedded and robotics
  open source — eProsima Fast-RTPS and Fast-CDR, FreeRTOS, Orange Pi BSP/u-boot/kernel, Yocto
  meta-layers (meta-tq, meta-dumpling), EIPScanner, xsens_standalone, Fusion, donkeycar, asio,
  tinyxml2 — plus a few small internal tools (RaiLTools, Doodlebot5000, two hackathon projects).
  There is no first-party Humatics SDK, client library or specification here, and no package named
  `humatics` exists on npm or PyPI.
